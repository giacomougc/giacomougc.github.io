# Giacomo Colomer — Portfolio UGC

Site une page pour Giacomo Colomer, créateur de contenu UGC à Nîmes.

- `index.html` : contenu de la page
- `style.css` : mise en forme
- `images/videos/` : miniatures des vidéos (posts LinkedIn)
- `videos/` : vidéo du haut de page

Aperçu en local : `python3 -m http.server 4340`, puis http://localhost:4340/
